# Sonic QR 2

نسخه دوم وب‌اپ محلی انتقال متن با صدا.

## اجرا

```bash
cd sonic-qr-v2
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. اجرای localhost برای دسترسی میکروفون ضروری است.

## دو حالت

- **سریع و شنیداری:** مدولاسیون 16-FSK و حدود ۲٫۵ برابر کوتاه‌تر از نسخه اولیه.
- **کم‌شنیدار روی وویس:** سیگنال فرکانس‌بالا که می‌تواند با وویس یا آهنگ ترکیب شود. برنامه می‌تواند دقیقاً به‌اندازه طول پیام، صدای پوششی ضبط کند.

## امنیت

پنهان یا کم‌شنیدار بودن، امنیت رمزنگاری محسوب نمی‌شود. برای داده حساس، در کادر «رمز اختیاری» یک رمز تعیین کنید؛ در این حالت پیام با AES-GCM و کلید مشتق‌شده با PBKDF2 رمز می‌شود.

## نکات حالت کم‌شنیدار

- کیفیت به میکروفون، بلندگو، codec و توانایی دستگاه در بازه فرکانسی بالا وابسته است.
- فایل WAV اصلی از MP3 و پیام‌رسان‌هایی که صدا را فشرده می‌کنند مطمئن‌تر است.
- اگر سیگنال هنگام پخش از بلندگو دریافت نشد، فایل اصلی را مستقیماً امتحان کنید.
